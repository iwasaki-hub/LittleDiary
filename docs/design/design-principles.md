# LittleDiary デザイン原則

## 目的
小さな出来事を一言日記として残し、将来はその言葉を英語学習につなげる。親しみやすく、ユーザーのペースを尊重する。Foundationでは機能を実装せず、以下を将来の設計資産として保持する。

## 見た目
Headspaceのやさしい雰囲気を参考にするが、ロゴ・画像・キャラクターをコピーしない。

| 用途 | 色 |
| --- | --- |
| 背景 | #FFF8EE |
| 文字 | #302B27 |
| 補助文字 | #817367 |
| アクセント・顔 | #FF935C |
| 日記カードの面 | #FFDEBF |
| 学習カード | #CDE8FA |
| 記録・英語例カード | #FFE8A6 |

カードは大きな余白と丸い角を使い、高さを固定せず文字量に合わせる。横並びは狭い画面で折り返す。丸顔キャラクターは独自の図形で表現し、装飾は読み上げ対象から外す。

## アクセシビリティ・設計
日本語と英語を読みやすく表示する。文字拡大、コントラスト、スクリーンリーダー、SafeArea、スクロール、ライト／ダークを実際に確認する。色だけで状態を表現しない。未実装の操作は準備中と明記し、操作できると誤認させない。
UI構造・文言は画面／コンポーネントに、色・余白・レイアウトはルート外のスタイルに分離する。これは将来のUI再導入方針であり、Foundation 0のプレースホルダーへ新UIは追加しない。
